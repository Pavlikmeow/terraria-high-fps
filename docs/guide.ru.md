# Использование High FPS Support

[English](guide.md) · [Русский](guide.ru.md) · [К README](README.ru.md)

## Выбрать правильную папку

В Steam откройте **Terraria → Свойства → Установленные файлы → Обзор**. В этой папке должны лежать оригинальный `Terraria.exe` и каталог `Content`. Укажите её в лаунчере: не папку архива, сохранений или tModLoader. Если библиотек Steam несколько, проверьте отображаемый путь.

Лаунчер со всеми распакованными файлами может оставаться в отдельной папке. В игру копируются только устанавливаемые компоненты. Выбор языка запоминается и не влияет на язык самой Terraria.

## Установить, играть и обновить

- **«Установить и играть»** — проверить совместимость, установить или обновить файлы и запустить игру.
- **«Играть»** — проверить текущую установку и запустить отдельный EXE.
- **«Установить / обновить»** — установить или восстановить мод без запуска игры.
- **«Технические детали»** — посмотреть диагностику при ошибке.

Перед изменением установки закройте Terraria и `Terraria.HighFPS`. Для игры оставьте Steam запущенным. Обычная кнопка Steam запускает оригинальную игру; для High FPS используйте лаунчер. Прямой запуск `Terraria.HighFPS.exe` возможен, но пропускает проверки целостности лаунчера.

Новый выпуск мода распаковывайте в отдельную папку и устанавливайте оттуда. Не смешивайте DLL разных выпусков. После обновления самой Terraria проверьте совместимость версии перед повторной установкой. Не обходите сообщение о несовместимости и не скачивайте старые EXE из неизвестных источников.

## Полное удаление

Закройте игру и нажмите **«Удалить High FPS»**. Для ручного удаления удалите из папки установки игры только:

```text
Terraria.HighFPS.exe
HighFPS.Support.dll
HighFPS.Support.install.txt
HighFPS.Support.log
```

После этого можно удалить распакованную папку лаунчера. По желанию удалите `%LOCALAPPDATA%\TerrariaHighFPS\game-path.txt` и `language.txt`, чтобы сбросить его настройки. Не удаляйте `Terraria.exe`, `Content`, файлы Steam и сохранения. Если после ошибки осталась папка восстановления, сначала прочитайте сообщение об ошибке.

Миры и персонажи не удаляются. Terraria может сохранить **Frame Skip: Off** в собственных настройках; после удаления выберите нужный режим в обычной игре.

## Решение проблем

| Проблема | Что сделать |
| --- | --- |
| Неподдерживаемая версия Terraria | Нужен выпуск мода для этой точной версии. Эта сборка поддерживает только 1.4.5.8. |
| Не найден Mono.Cecil или другой файл лаунчера | Заново полностью распакуйте ZIP в отдельную папку и проверьте хэши. |
| Установка изменена / ошибка целостности | Закройте игру, проверьте загрузку лаунчера, нажмите **«Установить / обновить»**. При сомнениях в оригинале сначала проверьте файлы Terraria через Steam. |
| Файл занят | Закройте все экземпляры Terraria, включая ещё завершающиеся, и повторите. |
| Нет доступа | Проверьте права записи в выбранную папку. Через настройки хранилища Steam можно перенести игру в доступную библиотеку. Лаунчер сам не повышает права. |
| Нет XNA / .NET | Запустите оригинал через Steam и завершите установку компонентов. Не скачивайте отдельные DLL с посторонних сайтов. |
| Ошибка Steam при запуске | Запустите Steam, убедитесь, что обычная игра открывается, затем повторите запуск через лаунчер. |
| Всё ещё выглядит как 60 FPS | Проверьте частоту монитора в Windows и запас производительности. Убедитесь, что запущен `Terraria.HighFPS.exe`; сравнивайте одну и ту же сцену. |
| Артефакты или неточный прицел | Проверьте поведение в оригинале, укажите частоту, масштаб и разрешение, опишите воспроизведение в Issue. Пока используйте обычную игру. |
| Предупреждение SmartScreen / антивируса | Проверьте источник и хэши, сохранив защиту включённой. Отсутствие подписи не доказывает ни вредоносность, ни надёжность. |

Локальный `HighFPS.Support.log` содержит запуск и ошибки модуля. Если игра упала до его загрузки, журнал может отсутствовать. Причину ошибки установки можно посмотреть в разделе **«Технические детали»** лаунчера. Перед публикацией диагностики уберите имя пользователя, пути и личные данные. Не прикладывайте EXE игры.
