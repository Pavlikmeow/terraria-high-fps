# High FPS Support

Лаунчер для более плавного движения в Terraria на мониторах с высокой частотой обновления. Между обычными 60 обновлениями игры в секунду мод рисует промежуточные положения персонажей, врагов, снарядов и выпавших предметов. Скорость игры остаётся прежней.

**Версия 1.1.0 · Steam Terraria 1.4.5.8 · Windows x86**

## Установка и запуск

Нужны оригинальная Steam Terraria 1.4.5.8 для Windows, .NET Framework 4.x и XNA Framework 4. Один раз запустите Terraria через Steam, чтобы установились необходимые компоненты. Другие версии игры, tModLoader и другие патчи EXE не поддерживаются.

1. Скачайте `HighFPS-Support-1.1.0-Terraria-1.4.5.8-win-x86.zip` из [Releases](https://github.com/Pavlikmeow/terraria-high-fps/releases) и полностью распакуйте архив.
2. Закройте Terraria, оставив Steam запущенным.
3. Откройте `HighFpsSupport.exe`, выберите язык и проверьте найденную папку игры. В ней должны находиться `Terraria.exe` и `Content`.
4. Нажмите **«Установить и играть»**. В следующий раз достаточно кнопки **«Играть»**.

Мод использует обычные сохранения Terraria, поэтому перед первым запуском сделайте резервную копию важных миров и персонажей. Он создаёт отдельный `Terraria.HighFPS.exe`, сохраняя оригинальный `Terraria.exe`. Запуск через Steam по-прежнему открывает обычную игру.

Мод включает **Frame Skip: Off**. Проверьте частоту монитора в настройках Windows. Для дополнительных кадров нужен запас производительности CPU/GPU: медленную игровую логику мод не ускоряет. Интерполяция может добавить визуальную задержку до одного тика и сглаживает не все анимации и эффекты.

**Обновить или восстановить:** закройте игру, распакуйте новый выпуск в отдельную папку и нажмите **«Установить / обновить»**. После обновления Terraria проверьте, поддерживает ли мод новую версию игры.

**Удалить:** закройте игру и нажмите **«Удалить High FPS»**. Оригинальная игра и сохранения останутся. Ручное удаление и решение проблем описаны в [руководстве](guide.ru.md).

## Как проверить скачанные файлы

Сравните SHA-256 архива с [контрольной суммой](release-hashes.md) той же версии:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath .\HighFPS-Support-1.1.0-Terraria-1.4.5.8-win-x86.zip
```

В ZIP есть `SHA256SUMS.txt` и скрипт проверки содержимого. Из распакованной папки выполните:

```powershell
powershell -NoProfile -File .\verify-release.ps1
```

Если скрипты заблокированы, сравните файлы с `SHA256SUMS.txt` через `Get-FileHash`. Не запускайте файлы с несовпадающими хэшами. У сборки нет цифровой подписи, поэтому Windows может показать неизвестного издателя. Хэши выявляют изменения файлов, но не заменяют аудит безопасности. Подробности и порядок сообщения об уязвимостях — в [Security](../SECURITY.md#русский).

## Разработка

Лаунчер с помощью Mono.Cecil добавляет три вызова около процедур обновления и отрисовки Terraria. Модуль запоминает координаты до тика, сглаживает их на время кадра и восстанавливает после отрисовки. В лаунчере нет телеметрии, автообновления и загрузок во время работы.
